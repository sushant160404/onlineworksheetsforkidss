HOW IT WORKS
================================================================================

When request arrives:
  1. Express server receives it
  2. Checks User-Agent header
  3. Is it a crawler (Googlebot, Bingbot, etc.)?
     YES → Render static HTML immediately → Send to bot (instant!)
     NO  → Serve React app → Browser hydrates → User has React experience

Result:
  • Crawlers get instant HTML with content
  • Users get interactive React app
  • Everyone sees proper meta tags for social sharing
  • Search engines can index everything

BUILD PROCESS
================================================================================

OLD:
  npm run build
  → Vite creates /dist/
  → React app ready

NEW:
  npm run build
  → Vite creates /dist/ (React app)
  → esbuild creates /dist/ssr.cjs (Node server)
  → Both included in production build

Run production:
  npm start
  → Starts Node.js SSR server
  → Serves both SSR HTML and React app
  → Listens on port 3000
